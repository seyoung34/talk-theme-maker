# iOS sample theme reference

This directory keeps a local copy of the KakaoTalk iOS sample theme used as the export filename and package-structure reference.

Source copied from:

`C:\Users\jupi4\Documents\kakaotalk_theme_user_guide\iOS_Sample_Theme_25.8.0\apeach-25.8.0`

Notes:

- `KakaoTalkTheme.css` must be at the package root.
- Image resources live under `Images/`.
- CSS image values use base names such as `chatroomBubbleSend01.png`.
- The actual image files use iOS scale suffixes such as `@2x` and `@3x`.
- `.DS_Store` files are intentionally not copied.
