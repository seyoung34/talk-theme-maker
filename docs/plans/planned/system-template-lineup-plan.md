# 시스템 템플릿·에셋 라인업 기획 — 첫인상과 완성 경험

일반 사용자가 `/template`에 처음 들어왔을 때 **"예쁘다(흥미)"** 와 **"이 정도면 나도 금방 만들겠다(편의)"**
를 동시에 느끼게 하는 시스템 템플릿·에셋 라인업 기획. 성장 기획의 활성화(Activation) 레버를
콘텐츠로 채우는 문서다.

> 상태: 기획 확정. 에셋 제작·저작권 정리 후 admin(`/admin/edit`)에서 순차 등록.
> 참고: 활성화(Aha) 지표·성장 맥락 → [../in-progress/service-growth-plan.md](../in-progress/service-growth-plan.md)
> 참고: 제품 정의·핵심 가치 → [../../architecture/roadmap.md](../../architecture/roadmap.md)

## 문제의식

- 현재 base template은 `basic` 하나뿐이고, `/template` 갤러리를 채울 **완성형 시스템 템플릿이 부족**하다.
- 일반 사용자에게 "빈 캔버스에서 시작"에 가까운 경험은 흥미도 진입 편의도 떨어뜨린다.
- 성장 기획의 Aha는 **"첫 세션 내 `export_completed` 도달"** 이다. 좋은 프리셋 = 최소 편집으로 완성 =
  활성화율↑. 즉 이 라인업은 활성화 지표를 직접 끌어올리는 콘텐츠 투자다.

## 설계 원칙 (제품 제약 반영)

- 시스템 템플릿은 **`basic + overrides`** 로만 만든다. 새 base template을 만들거나 base를 통째로
  복사하지 않는다(프로젝트 코어 규칙). 라인업의 다양성은 색·배경·말풍선·탭 아이콘·프로필/스플래시
  **overrides 조합**으로 구현한다.
- 저작 경로는 기존 admin `/admin/edit` → 시스템 템플릿 저장(published/public). 신규 툴은 만들지 않는다.
- 관리형(시스템) 템플릿 persistence는 사용자 로컬 템플릿과 분리 유지(코어 규칙 상속).
- 초기 라인업은 **전부 무료(`pricingType: "free"`)** 로 공개해 유입·활성화를 우선한다. 유료/크레딧
  템플릿은 성장 기획 Phase 3에서 별도 검토.

## 두 축: 흥미 × 편의

### 흥미(Interest) — 갤러리 첫인상
- 무드/컨셉이 뚜렷한 완성형 프리셋으로 갤러리 상단을 채운다.
- 썸네일은 실제 적용 미리보기에 가깝게(메인+채팅방이 한눈에). 첫인상이 곧 이탈/시작을 가른다.
- "추천"/신규/시즌 배지로 시선 유도(갤러리에 이미 "추천" 배지 존재).

### 편의(Ease) — 최소 편집으로 완성
- 각 템플릿은 **"색만 바꿔도 말이 되는" 구조**로 설계(배경·말풍선·탭이 하나의 팔레트로 묶임).
- 사진 없이도 완성되는 그라데이션/단색/패턴 배경을 기본 포함 → 업로드 없이 내보내기 가능.
- 편집 부담이 큰 슬롯(9-patch 말풍선, 탭 아이콘)은 프리셋이 이미 채워두어 **손대지 않아도 완성**되게.

## 시스템 템플릿 라인업 (초안, 무드 8종)

`basic + overrides`로 달성 가능한 범위에서 무드별로 나눈다. 명칭·수량은 제작 여건에 맞춰 조정.

| # | 무드/컨셉 | 핵심 overrides | 편의 포인트 |
|---|---|---|---|
| 1 | 미니멀 화이트 | 밝은 단색 배경, 중립 말풍선, 얇은 탭 아이콘 | 색만 바꿔도 완성 |
| 2 | 다크 모드 | 딥 그레이 배경, 고대비 말풍선 | 야간 선호층, 업로드 불필요 |
| 3 | 파스텔 소프트 | 파스텔 그라데이션 배경, 라운드 말풍선 | 사진 없이 완성 |
| 4 | 뉴트로/레트로 | 채도 있는 배경색, 각진 말풍선 | 팔레트 프리셋만 교체 |
| 5 | 모노 그라데이션 | 단색→투명 그라데이션, 심플 아이콘 | 배경 1개로 통일감 |
| 6 | 시즈널(봄/여름/가을/겨울) | 계절 컬러 팔레트 + 배경 패턴 | 시즌 배지로 흥미 유도 |
| 7 | 러블리 하트/도트 | 은은한 패턴 배경, 소프트 말풍선 | 패턴 배경 재사용 |
| 8 | 딥 톤(네이비/버건디) | 저채도 딥 배경, 골드 포인트 | 고급스러운 첫인상 |

> 시즈널은 1종을 계절별 색 팔레트 변주로 재사용해 제작비를 아낀다.

## 에셋 팩 (템플릿의 재료)

시스템 템플릿을 구성하고, 사용자가 편집 중에도 후보로 고를 수 있는 공용 에셋.

1. **배경 팩**: 그라데이션·단색·은은한 패턴(도트/스트라이프/노이즈). 사진 없이 완성되는 핵심 재료.
2. **말풍선 스타일 팩**: 라운드/각짐/말꼬리 유무 등 9-patch·iOS inset 세팅이 끝난 프리셋.
3. **탭 아이콘 세트**: 무드에 맞는 선/면 아이콘 세트(포커스/비포커스 쌍 완비).
4. **프로필·스플래시 기본 이미지**: 업로드 안 해도 어색하지 않은 중립 이미지.
5. **컬러 팔레트 프리셋**: 에셋이 아니라 색 조합. "테마 색 한 번에" — 편의의 핵심(추후 UI 검토).

## 갤러리·UX 연동 (구현 시)

- 무드/시즌 **카테고리 필터**와 "무료" 강조 배지로 탐색을 쉽게 한다.
- 추천/신규/시즌 배지로 상단 노출 순서를 운영한다.
- 썸네일 품질을 우선 확보(첫인상 지표에 직결). 저품질 썸네일은 등록 보류.
- 상세 진입 시 "이 템플릿으로 시작" → `/edit` 직행, 최소 편집 동선을 해치지 않는다.

## 성장 지표 연결

- 시스템 템플릿별 **시작 수·내보내기 완료 수·완료율**을 성장 기획의 대시보드와 연결
  (`template_started`/`export_completed`의 `template_key`).
- 활성화율(첫 세션 Aha 도달)을 라인업 도입 전/후로 비교해 콘텐츠 투자 효과를 검증한다.
- 관리형 에셋 포함률(성장 기획 Phase 3)은 이 에셋 팩의 실사용도 측정으로 이어진다.

## 저작권·운영 제약

- 배경 사진·캐릭터·폰트는 **자체 제작 또는 상업 이용 가능 라이선스가 명확한 것만** 사용한다.
  라이선스 미확인 에셋은 등록하지 않는다.
- 카카오톡 상표·기본 UI 에셋을 그대로 재배포하지 않는다(테마 제작 범위 내 사용에 한정).
- 시스템 템플릿은 admin에서 `published` + `public`으로 공개하고, 초안은 `draft`로 관리한다.

## 단계별 로드맵

- [ ] **Phase 1 — 스타터 3종**: 미니멀 화이트·다크·파스텔. 배경/말풍선/탭 팩 최소분 제작 → admin 등록 → 갤러리 노출.
- [ ] **Phase 2 — 라인업 확장**: 나머지 무드 + 시즌 1세트, 카테고리 필터·배지 운영.
- [ ] **Phase 3 — 데이터 기반 큐레이션**: 템플릿별 완료율로 상위 노출·저성과 교체, 유료/크레딧 템플릿 검토.

## 완료 기준

- 갤러리에 무료 시스템 템플릿이 **최소 3종(Phase 1)** 완성형으로 노출되고, 각 썸네일이 실제 적용
  결과에 가깝다.
- 각 템플릿은 **업로드 없이도 내보내기까지 완성**된다(사진 없이 완결).
- 시스템 템플릿별 시작/완료율이 대시보드에서 확인되고, 라인업 도입 전후 활성화율을 비교할 수 있다.
- 등록된 모든 에셋의 저작권·라이선스 근거가 확인되어 있다.

## 다음 단계

1. (기획) Phase 1 스타터 3종의 색 팔레트·배경·말풍선 무드 확정.
2. (제작) 배경·말풍선·탭 아이콘 최소 팩 제작 + 라이선스 정리.
3. (등록) admin `/admin/edit`에서 `basic + overrides`로 저장 → published/public.
4. 검증: `/template` 갤러리 노출·썸네일 품질 확인, 각 템플릿 업로드 없이 내보내기 완결 확인.
