# 후보 레이아웃 QA 보고서

작성일: 2026-07-28

## 목적

테마 편집기의 후보 선택 영역을 슬롯 유형별로 더 효율적으로 표시하고, 모바일에서 더 많은 후보가 있다는 사실을 사용자가 쉽게 알 수 있도록 개선했다.

## 반영 내용

- 기본 후보는 별도 칩으로 분리하지 않고 이미지 슬롯에서는 `추천 에셋`의 첫 번째 후보로, 색상 슬롯에서는 `팔레트`의 첫 번째 후보로 배치했다.
- 데스크톱 후보 영역은 기본 상태에서 가로 스크롤로 간단히 보여 주고, `전체 보기`에서는 슬롯 유형에 맞는 그리드로 표시한다.
  - 일반 이미지: 최대 5열
  - 세로 배경: 최대 6열, 1:2 비율
  - 색상: 최대 7열
- 모바일 전체 시트에서는 슬롯 유형별 후보 밀도를 적용했다.
  - 일반 이미지: 390px 기준 4열, 430px 이상 5열
  - 세로 배경: 3열, 430px 이상 4열
  - 색상: 6열, 430px 이상 8열
- 반쯤 열린 모바일 편집 시트의 이미지 슬롯 헤더에 `펼쳐 보기`를 제공했다. 선택하면 시트가 전체 높이로 열려 후보 그리드를 바로 확인할 수 있다.
- 모바일 슬롯명 아래의 이미지 파일명·상태 표시는 제거했다. 슬롯명과 후보 선택에 필요한 정보만 남긴다.
- 후보 카드의 이미지 박스 내부 테두리를 제거하고, 선택 상태는 카드 외곽 테두리로만 표시했다.
- 업로드 후보는 각 카드의 삭제 버튼으로 개별 삭제한다.

## QA 결과

- 데스크톱 1440px 화면에서 일반 이미지 후보 `전체 보기`가 5열로 표시되는 것을 확인했다.
- 모바일 390 x 844px 화면에서 `펼쳐 보기`가 반쯤 열린 시트에 나타나며, 선택 후 전체 시트의 일반 이미지 후보가 4열로 표시되는 것을 확인했다.
- 모바일 슬롯 헤더와 선택 슬롯 목록에서 이미지 파일명 보조 텍스트가 보이지 않는 것을 확인했다.
- 브라우저 콘솔 오류: 0건.
