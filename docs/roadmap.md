# 카카오톡 테마 메이커 로드맵

## 제품 정의

카카오톡 테마 메이커는 템플릿 기반으로 Android/iOS 카카오톡 테마를 제작하고, 실제 적용 결과에 가까운 미리보기로 검수한 뒤 플랫폼별 결과물로 내보내는 내부 제작 도구다.

핵심 가치는 아래 3가지다.

1. 정해진 파일명과 규격을 외우지 않고도 제작할 수 있어야 한다.
2. 미리보기 결과와 실제 적용 결과의 차이가 작아야 한다.
3. 템플릿을 바탕으로 빠르게 반복 제작할 수 있어야 한다.

## 현재 상태

- `/template`에서 템플릿을 고른 뒤 플랫폼을 고정해서 시작할 수 있다.
- `/edit`에서 메인 화면, 하단 탭, 채팅방 중심으로 슬롯 편집과 미리보기가 가능하다.
- `/edit` 안에서 Android 9-patch, iOS inset/stretch를 정밀 조절할 수 있다.
- 후보 이미지, 세션 업로드, 기본 템플릿 에셋 구조가 이미 들어가 있다.

## 제품 우선순위

### 1차 목표

테마 제작 흐름을 끝까지 닫는다.

- 템플릿 선택
- 화면별 편집
- 미리보기 검수
- Android/iOS export

### 2차 목표

전체 테마 단위 운영성과 재사용성을 높인다.

- 템플릿 manifest 체계
- 섹션/슬롯 확장
- 진단 및 검수 자동화
- 에셋 운영 효율화

### 3차 목표

제작 도구에서 운영 도구로 확장한다.

- 템플릿 라이브러리 확장
- 제작자용 에셋 관리 체계
- 대량 제작/복제 워크플로우

## 단계별 개발 계획

## Phase 1. Preview Fidelity 고도화

목표: 미리보기 신뢰도를 올린다.

범위:

- Android `.9.png` 렌더 정확도 보강
- iOS inset/stretch 반영 정확도 보강
- 채팅방 말풍선 크기/텍스트 줄바꿈/입력바 비율 보정
- 메인 화면, 하단 탭, 채팅방 비율 조정
- 슬롯별 실제 반영 위치와 미리보기 선택 영역 일치

완료 기준:

- 같은 에셋을 실제 테마에 넣었을 때 프리뷰와 체감 차이가 작다.
- 제작자가 프리뷰만 보고도 적용 결과를 예측할 수 있다.

## Phase 2. Export 파이프라인 구축

목표: 제작 결과를 실제 배포 가능한 형태로 만든다.

범위:

- Android export
  - 샘플 테마 복사
  - 리소스 파일 치환
  - 색상/설정값 반영
  - 빌드 전 진단
- iOS export
  - `Images/` 구성
  - `KakaoTalkTheme.css` 반영
  - `.ktheme` 패키징
  - 누락 파일/스케일 검수

완료 기준:

- Android/iOS 각각에서 기본 템플릿 하나 이상을 export할 수 있다.
- export 전 필수 슬롯 누락과 잘못된 규격을 잡아낸다.

## Phase 3. 전체 테마 프로젝트 구조 정착

목표: 슬롯 편집기를 프로젝트 편집기로 승격한다.

범위:

- 템플릿 manifest 도입
- 플랫폼별 파일명 매핑 정리
- 섹션/그룹/슬롯 정의 표준화
- candidate/override/export source 분리
- 프로젝트 저장 포맷 확정

완료 기준:

- 템플릿 추가 시 코드 수정 범위가 줄어든다.
- 한 템플릿이 Android/iOS 양쪽에 일관되게 연결된다.

## Phase 4. 진단과 검수 화면 추가

목표: 테마 제작 실패 원인을 도구 안에서 해결하게 만든다.

범위:

- 누락 슬롯 진단
- 잘못된 파일명 진단
- Android 9-patch invalid border 진단
- iOS `@2x/@3x` 누락 및 비율 진단
- export 가능 상태 체크리스트

완료 기준:

- 빌드 실패나 적용 실패 원인을 도구 안에서 먼저 확인할 수 있다.

## Phase 5. 화면 범위 확장

목표: 1차 MVP 범위를 넘어 전체 테마 체감을 더 넓힌다.

확장 후보:

- 친구 목록 세부 요소
- 프로필
- 더보기
- 잠금 화면
- 알림/직접 공유

원칙:

- 체감이 큰 화면부터 확장한다.
- 프리뷰와 export 매핑이 준비된 항목만 추가한다.

## 실행 순서 추천

1. Preview fidelity 보강
2. Android/iOS export 구현
3. 프로젝트 데이터 모델 확정
4. 진단/검수 화면 추가
5. 추가 화면 확장

## 이번 버전의 핵심 범위

이번 버전에서 “완성”으로 보는 범위는 아래와 같다.

- 메인 화면
- 하단 탭 5종
- 채팅방
- 채팅 입력바
- Android/iOS 기본 export

프로필, 잠금, 알림, 공개 마켓, 결제는 후속 작업으로 둔다.

## 설계 원칙

- 일반 편집과 고급 편집을 분리한다.
- 템플릿 기본값은 항상 존재해야 한다.
- 업로드는 템플릿 기본값을 덮는 override로 본다.
- 미리보기와 export는 같은 데이터 모델을 바라봐야 한다.
- 플랫폼 차이는 UI에서 숨기되, 내부 export 로직은 분리한다.

## 리스크

- 카카오톡 실제 적용 결과와 프리뷰 차이가 커지면 도구 신뢰도가 떨어진다.
- 템플릿/슬롯 정의가 코드 곳곳에 흩어지면 확장성이 급격히 낮아진다.
- export 없이 편집 기능만 늘리면 도구가 중간 단계에서 멈춘다.
